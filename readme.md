# Mobile Development Retrofit demo 2026 - 2027

Deze demo werkt met een 2e versie van de API die we vorig jaar tijdens de module Dynamic Web Development hebben gebruikt.

Die API kan gevonden worden op https://stevenop.be/market/v2/

Deze demo demonstreert het ophalen van gegevens, het toevoegen en het verwijderen van producten. 

Ook zie je hoe je met Coil afbeeldingen kan tonen via een url.

Let op dat bij het aanmaken van nieuwe producten, de id een random gegenereerde id is. Dat zal niet de effectieve id zijn die door de API wordt toegekend. Daardoor zal de delete voor dat product ook een fout geven. Als je opnieuw de producten ophaalt, kan die wel verwijderd worden (tenzij iemand anders ondertussen dat product heeft verwijderd ;-)
